# Ilosin's DSA Wuerfel - Fork of Dive's DnD Dice

## English

**This mod is a fork of [Dive's DnD Dice - RPG Dice Roll for Zeus](https://github.com/dive155/arma3-dives-simple-dice-roll).**  
It adapts the original mechanics to support **The Dark Eye (Das Schwarze Auge)** rule system.

### Key Changes in This Fork

- Rolls are evaluated using **The Dark Eye-style mechanics**:
  - A roll is successful if the result is **less than or equal to the difficulty/value**.
  - The **highest possible dice result** counts as a **critical failure**.
  - A roll of **1** always counts as a **critical success**.
- All other functionality remains largely identical to the original mod.

### Included Dice

D4, D6, D8, D10, D12, D20, D100  
*D10 values run from 0–9 to replicate real-world dice behavior; all other dice start at 1.* (as in the orginal mod)

- German

## Deutsch

**Dieses Mod ist ein Fork von [Dive's DnD Dice - RPG Dice Roll for Zeus](https://github.com/dive155/arma3-dives-simple-dice-roll).**  
Es passt die ursprünglichen Mechaniken an das **Das Schwarze Auge (DSA)** Regelwerk an.

### Änderungen in diesem Fork

- Würfe werden nach **DSA-Mechanik** ausgewertet:
  - Ein Wurf ist erfolgreich, wenn das Ergebnis **kleiner oder gleich dem Zielwert** ist.
  - Das **höchstmögliche Würfelergebnis** gilt als **kritischer Fehschlag/Patzer**.
  - Eine **1** zählt immer als **kritischer Erfolg**.
- Alle anderen Funktionen bleiben größtenteils identisch mit der Original Mod.

### Enthaltene Würfel

D4, D6, D8, D10, D12, D20, D100  
*Der D10 läuft von 0–9, um echte Würfel nachzubilden; alle anderen Würfel starten bei 1.* (wie in der originalen Mod)
